# GlucoCheck
GlucoCheck giúp người trưởng thành tự sàng lọc nguy cơ tiểu đường tại nhà qua 7 câu hỏi, rồi gợi ý có nên xét nghiệm đường huyết hay không. Mô hình học từ 253.680 khảo sát CDC (AUC 0,81), giải thích yếu tố ảnh hưởng, mô phỏng ngưỡng theo chi phí, kiểm tra công bằng, hỗ trợ 4 ngôn ngữ. Chỉ mang tính giáo dục, không thay thế bác sĩ.
